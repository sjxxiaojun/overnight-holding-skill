# 隔夜持股 (Overnight Holding)

这是一个用于 A 股短线交易的自动化智能分析技能。它的核心逻辑是每天尾盘（建议 14:30）扫描当前市场的全量数据，并根据前一日推荐标的在今日的胜率，动态放宽或收紧选股过滤参数，从而为您筛选出最佳的次日冲高潜伏标的。

## 触发条件与使用时机
当用户提及“运行隔夜持股”、“尾盘扫描”、“今天买什么”、“跑一下 overnight-holding”，或者在 14:30 的定时任务触发时，请无条件调用此技能。

## 执行步骤

1. **环境确认**：
   此技能的底层引擎位于 `overnight_engine.py`。
   状态文件位于 `state.json`。

2. **执行引擎**：
   ```bash
   python overnight_engine.py
   ```

3. **解析与推送**：
   引擎执行完毕后，提取并以优美的 Markdown 格式汇报以下关键内容：
   - **历史验证结果**：昨天的推荐在今天的真实胜率是多少（>2%的冲高率）。
   - **参数动态调整状态**：当前系统处于“进攻模式（放宽阈值）”还是“防守模式（收紧阈值）”。
   - **今日尾盘潜伏名单**：给出的候选标的名称、代码和建议买价。

4. **处理空仓防守**：
   如果在输出中【建议尾盘潜伏名单】为空，请明确提示：“今日引擎未扫出满足严苛形态的标的，触发防守机制，建议空仓。”（宁缺毋滥原则）。

## 注意事项
- 请勿随意修改引擎内的底层逻辑。
- 引擎自带网络重试机制和断点记录。
- 采用自适应参数，前一日胜率低于 50% 自动收紧过滤条件（防守模式），大于 70% 自动放宽（进攻模式）。
