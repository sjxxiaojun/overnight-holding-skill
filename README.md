# 隔夜持股 (Overnight Holding) · Alpha V3 Shield 架构

这是一个专为 A 股短线交易打造的自动化量化研判与尾盘潜伏引擎。核心目标是在每日尾盘（14:30 前后）对核心主题标的池进行全维度量价形态扫描与大盘风控，挑选出次日开盘具备高概率冲高（>2% 溢价兑现空间）的优质标的。

---

## 🌟 核心架构升级 (Alpha V3 Shield)

针对弱市、缩量轮动与单边下杀行情，引擎深度集成了四大防御与进攻杀手锏：

1. **大盘双破位熔断机制 (Circuit Breaker)**：
   - 每日开盘前首先检测大盘基准指标：当上证指数收盘同时跌破 5 日线与 10 日线，且近 3 日动量呈下行破位走势时，系统强制触发全天 100% 空仓熔断，杜绝单边下杀日的系统性回撤。
2. **动态板块超额收益扫描与主线抱团 (Sector Relative Momentum)**：
   - 实时计算 10 大核心赛道近 5 日相对大盘超额收益排名；
   - 严格封杀并剔除失血严重、资金退潮的落后板块；
   - 允许资金共识最高的领涨主线（如 CPO / PCB 等）配置至多 2 只标的，彻底解决弱市中机械分散到失血板块的弊端。
3. **底底抬高硬过滤 (Higher Lows Streak)**：
   - 强制要求当日最低价不破昨日低点（`Low >= Yesterday Low`），仅在主力真金白银护盘、底部逐级抬高的形态中精选，拒绝半山腰接下坠飞刀。
4. **相对大盘强势与 5 日线支撑 (RS5 & Close >= MA5)**：
   - 个股近 5 日走势必须强于大盘（`RS5 >= 0.005`），且收盘价站稳 5 日均线，拒绝阴跌中继的弱势标的。
5. **出镜冷却衰减机制 (Cooling Penalty)**：
   - T-1 扣 20 分，T-2 扣 10 分，杜绝同一只票连续多日无脑霸榜，保持选股池动态换血。

## 🚀 快速开始

### 1. 运行环境
- Python 3.9+
- 依赖项：`baostock`, `pandas`, `numpy`

```bash
pip install baostock pandas numpy
```

### 2. 执行引擎
```bash
# 自动抓取最新交易日并执行扫描
python overnight_engine.py

# 指定日期回测/复盘
python overnight_engine.py --date 2026-09-18

# 重置参数至默认状态
python overnight_engine.py --reset
```

## 📊 引擎输出与交互规范

引擎执行后输出结构清晰的 Markdown 研报，包含：
1. **历史验证结果**：核验前一交易日推荐标的在今日的真实冲高情况（次日最高价是否达成 >2% 溢价）。
2. **大盘风控与板块雷达**：检测是否触发熔断空仓，输出当日领涨主线与严重失血避坑方向。
3. **今日尾盘潜伏名单**：精选标的名称、代码、信号价、评分、仓位及触发区间，并配套生成操盘计划。
4. **严禁抄底避坑名单**：列出形态破位或板块失血的高危标的。
